# 미세조류 연중생산 시스템: 투자비 최소화와 급이(혼합영양) 제어

배양시스템 구축비는 **① 배양기(PBR)**, **② 에어돔** 순으로 많이 듭니다.
이 폴더는 두 항목의 투자비를 낮추면서 **한국 기후에서도 1년 내내 생산하는** 전략을 정리하고,
그 전략을 실행하는 **급이 계획기와 실시간 급이 제어기**를 코드로 제공합니다.

```
microalgae/
├── README.md                      ← 이 문서 (기술 분석 · 전략 · 급이 프로토콜)
├── run.py                         ← 최적화 + 급이 계획 + 제어기 검증 실행
├── algae_feed/
│   ├── config.py                  ← 균주·기후·배양기·에어돔 카탈로그, 단가 (견적 받으면 여기만 수정)
│   ├── model.py                   ← 월별 광합성/급이 생산, 가온, 영양염, 원가·면적 산정
│   ├── optimizer.py               ← 195개 조합 전수 탐색 → 연중생산 조건 하 최저원가
│   ├── controller.py              ← 실시간 급이 제어기 (CO2 pH-stat, 포도당 DO-stat, N/P, 수확, 온도)
│   └── sim.py                     ← 1분 단위 배양기 동역학 (제어기 검증용)
├── tests/test_algae_feed.py       ← 13개 단위 테스트
└── docs/sample_report_korea_100t.md  ← 한국 중부 · 연 100 t 실행 결과 예시
```

## 1. 세계 기술 분석

### 1.1 배양기 형식별 비교

| 형식 | 대표 적용 지역·사례 (공개 정보 기준) | 장점 | 한계 | 연중생산 적합도 |
|---|---|---|---|---|
| **유리 튜브형 PBR** | 독일 Klötze (Chlorella), 이스라엘 Negev (Haematococcus), 포르투갈 Pataias, 스페인 Almería 연구단지 | 위생·품질 최고, 고부가 제품 | **m² 당 투자비 최고**, 탈기 구간 필요, 고온 과열 | 외피+가온 시 가능 |
| **경질 평판형 (에어리프트)** | 독일 Subitec, 네덜란드 Wageningen AlgaePARC 비교시험 | 수직 배치로 빛이 넓게 퍼져 광효율이 높음, 혼합 간단 | 패널 단가가 높고 대형화하면 구조비가 커짐 | 높음 |
| **필름(PE) 평판·행잉백** | 이탈리아 Florence의 Green Wall Panel, 벨기에 Proviron 저가 필름 평판, 수산 사료용 행잉백 | **최저가 폐쇄형**, 필름 교체로 세척 문제 해결 | 바람·자외선에 약함 → **외피 안에서만** 운용 | **에어돔과 결합 시 최적** |
| **박막 캐스케이드** | 체코 Třeboň, 스페인 Almería | 10 g/L 이상 고농도, 수확비 절감 | 반개방이라 유기탄소 급이 시 오염 위험 | 중간 |
| **레이스웨이 개방지** | 미국 하와이·캘리포니아, 중국 내몽골, 인도 (Spirulina) | 투자비 최저 | 생산성 낮음, 오염, **겨울에 생산이 거의 멈춤** | 열대 외 불가 |
| **종속·혼합영양 (발효)** | 대만·일본 Chlorella 산업, 포르투갈 (PBR과 발효조 병행), 이스라엘 Brevel (조명 보조 발효), 미국 Heliae | 빛과 무관하게 생산성이 높음 | 당 원가, 무균 운전, 색소·단백질 조성 변화 | 높음 (빛 의존도 낮음) |
| **실내 LED + 지열** | 아이슬란드 Vaxa | 계절과 무관 | 전력 단가가 낮아야만 성립 | 높음 (전력비 의존) |

### 1.2 외피(Enclosure) 비교

| 외피 | 투과율 | 단열(U) | 특징 |
|---|---|---|---|
| 유리 온실 (벤로형) | ~0.72 (골조 그림자) | 6 W/m²K | 골조가 많고 단열이 약함 |
| **에어돔 이중 PE 공기막** | ~0.78 | **4 W/m²K** | 기둥 없이 넓은 공간을 덮음. 필름은 4~5년마다 교체 |
| 에어돔 ETFE 쿠션 | ~0.90 | 2.9 W/m²K | 투과율·수명 최고, 초기비용 큼 |

### 1.3 분석에서 얻은 결론

1. **세계 상업 플랜트의 원가는 배양기 m² 단가보다 m² 당 연간 생산량에 좌우됩니다.** 배양기가 가장 비싸므로
   *같은 생산량을 더 적은 배양기 면적으로* 내는 쪽이 투자비를 가장 크게 줄입니다.
2. 겨울 광량 부족을 빛만으로 메우면 배양기를 2~3배 더 깔아야 합니다. 대만·일본·포르투갈의 Chlorella 산업처럼
   **유기탄소를 급이(혼합영양)** 하면 같은 배양기에서 겨울에도 생산이 이어집니다.
3. **필름형 PBR이 비싼 이유인 구조 강도와 내후성을 에어돔이 대신 맡으면** 배양기는 프레임과 일회용 필름만으로 지을 수 있습니다.
   즉 에어돔은 비용 항목인 동시에 배양기 비용을 줄이는 수단입니다.

## 3. 급이(Feeding) 프로토콜

### 3.1 무엇을, 얼마나 주는가 (바이오매스 1 kg 당)

| 급이 물질 | 역할 | 양 | 제어 방식 |
|---|---|---|---|
| CO2 | 광합성 탄소원 | 광합성분 1.83 kg ÷ 이용률 0.7 ≈ **2.6 kg** | **pH-stat**: pH > 7.6 이면 ON, < 7.45 이면 OFF |
| 포도당 (또는 당밀·전분 당화액) | 혼합영양 탄소원 | 급이분 1 kg 당 **2.0 kg** (수율 0.5) | **DO-stat 펄스**: 잔류당 < 0.10 g/L 이고 DO ≥ 40 % 일 때만 0.35 g/L(DO > 250 %면 0.5 g/L)까지 보충 |
| 질소 (요소) | 단백질 | N 0.08 kg = 요소 **0.17 kg** | 측정값 < 60 mg/L 이면 150 mg/L까지 보충, 측정값이 없으면 성장량 비례 feed-forward |
| 인 (KH2PO4) | 핵산·ATP | P 0.012 kg = KH2PO4 **0.053 kg** | 측정값 < 8 mg/L 이면 20 mg/L까지 보충 |
| Mg·S·Fe·미량원소 | 엽록소·효소 | 약 0.04 USD/kg 상당 | 수확 후 보충 배지에 포함 |

### 3.2 오염 방지 규칙 (급이 운전의 핵심 리스크)

- **잔류당 상한 0.5 g/L.** 당이 남아 있으면 세균이 먼저 먹습니다. 제어기는 이 상한을 넘겨 투입하지 않습니다.
- **DO < 40 % 이면 급이를 멈춥니다.** 산소가 부족한 상태에서 당을 넣으면 발효가 일어나고 오염을 부릅니다.
- **소비속도 감시.** 실측 당 소비가 예측의 2.5배를 넘으면 오염으로 보고 **포도당 급이를 자동 차단**하고 경보를 냅니다.
- **일일 예산.** 월별 계획이 내려 준 하루 포도당량의 1.1배를 넘기지 않습니다.
- 개방형(레이스웨이)이나 반개방형(박막, 무균도 0.35)은 모델이 급이를 막거나 제한합니다.

### 3.3 월별 급이 계획 (추천안, 플랜트 전체 1일)

`python3 run.py`를 실행하면 `out/feeding_plan.csv`와 리포트 4장에 월별 포도당·CO2·요소·KH2PO4·수확량·가온열량이 나옵니다.
예시는 [docs/sample_report_korea_100t.md](docs/sample_report_korea_100t.md)에 있습니다.

## 4. 실시간 급이 제어기 (`algae_feed/controller.py`)

```python
from algae_feed.config import STRAINS
from algae_feed.controller import FeedController, ControllerConfig, Sensors, daily_glucose_budget

ctl = FeedController(STRAINS["chlorella"],
                     ControllerConfig(x_opt=2.5, daily_glucose_budget_g=daily_glucose_budget(41.7, 100)))
# 1분마다 PLC/센서에서 읽어서 호출
act = ctl.step(Sensors(hour=13.5, ph=7.63, do_pct=180, temp_c=24.1, par_umol=950,
                       biomass_g_l=2.7, volume_l=4500, glucose_g_l=None, no3_n_mg_l=None), dt_h=1/60)
# act.co2_on, act.glucose_ml, act.n_ml, act.p_ml, act.harvest_l, act.heater_on, act.cooler_on, act.alarms
```

- 순수 로직만 담겨 있어 Modbus, OPC-UA, MQTT, 아두이노, PLC 어디에든 I/O 계층만 붙이면 됩니다.
- 당 센서나 질산염 센서가 없으면 모델 추정값으로 대신 운전하고, 센서가 있으면 실측값으로 보정합니다.
- 월별 계획(`model.simulate`)이 정한 일일 포도당 예산 안에서 운전하므로 계획과 현장이 서로 맞물립니다.

시뮬레이션 검증 (배양기 100 m² 모듈, 1월·7월): pH 7.0~7.6, DO 평균 70~80 %, 경보 0건이었습니다. 일일 포도당 예산은 모두 투입되었고 약 0.47 g/g 수율로 바이오매스가 되었습니다.

## 5. 실행

```bash
cd microalgae
python3 run.py                                   # 한국 중부, Chlorella, 연 100 t
python3 run.py --tpy 300 --climate korea_jeju    # 제주, 300 t
python3 run.py --strain spirulina --min-ratio 0.4
python3 run.py --glucose-cost 0.30 --heat-cost 0.015   # 저가 당·폐열 확보 시
python3 -m unittest discover -s tests -v
```

외부 패키지 없이 Python 3.10 이상 표준 라이브러리만 사용합니다.

## 6. 다음 단계 제안

1. **견적 반영**: 에어돔(PE 이중막·ETFE) 업체와 필름 PBR 업체 견적을 `config.py`에 입력해 다시 실행합니다.
2. **100 m² 파일럿**: 에어돔 1동에 필름 패널을 넣고 제어기를 붙여 겨울 1개월 혼합영양 운전으로 `mu_het_max`, `yield_glucose`, `otr_g_per_l_day`를 실측합니다.
3. **저가 탄소원**: 전분 당화액·당밀·식품 부산물, 그리고 배가스 CO2(0.02~0.05 USD/kg)를 확보하면 원가가 추가로 내려갑니다.
4. **폐열 연계**: 가온이 원가의 약 20 %(1.06 $/kg)를 차지하므로 발전소·소각장·데이터센터 폐열 옆에 입지하는 것이 가장 효과가 큽니다.
